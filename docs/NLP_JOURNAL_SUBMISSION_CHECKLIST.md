# Natural Language Processing Journal Submission Checklist

Before submitting the manuscript to *Natural Language Processing*, strengthen the software and reproducibility package as follows.

## Minimum recommended package state

- [ ] Public GitHub repository available.
- [ ] MIT, Apache-2.0, or similar open-source license added.
- [ ] Installation works with `pip install -e .`.
- [ ] Unit tests pass with `pytest`.
- [ ] Synthetic or anonymised sample corpus included.
- [ ] Full private corpus is not accidentally committed.
- [ ] Reproducibility script regenerates core paper tables.
- [ ] README explains the NLP task, data schema, and use cases.
- [ ] Manuscript includes repository URL and version tag.
- [ ] Release archive created on Zenodo or similar if required.

## Suggested framing

The paper should be framed as an applied NLP framework for translation-process analytics, not merely as a classroom tool. Emphasize:

1. view-aware corpus representation;
2. Arabic-sensitive preprocessing;
3. MT-to-submission comparison;
4. transparent edit-distance metrics;
5. reproducible resource-oriented workflow;
6. limitations and ethical handling of student data.
