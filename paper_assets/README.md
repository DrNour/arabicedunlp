# Paper Assets

This folder contains aggregate, non-identifying tables derived from the uploaded classroom corpus. The private row-level student corpus is intentionally not included in the repository.

Files:

- `corpus_summary_public_from_uploaded_corpus.json`
- `table_corpus_composition_from_uploaded_corpus.csv`
- `table_descriptives_by_task_from_uploaded_corpus.csv`
- `table_overall_descriptives_from_uploaded_corpus.csv`

Use these aggregate files for manuscript reporting. Use `scripts/reproduce_paper_tables.py` with the private corpus path to regenerate them locally.
